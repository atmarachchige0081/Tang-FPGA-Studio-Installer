## Studio release notes

Tang Primer FPGA Studio v1.2.0 makes the complete beginner path clearer—from the first RTL module to verified hardware.

Highlights:
- searchable synthesized-netlist viewer with categorized overview, local fan-in/fan-out, zoom/pan, and RTL navigation;
- visual first-launch release notes shown once per version and always available from Help;
- guided project creation, HDL definitions/references/instance generation, verification selection, and clickable diagnostics;
- integrated read/write UART terminal plus a complete greeting/echo learning project;
- natural accessible dark/light themes, guided JTAG/UART setup, and 72 reviewed HDL patterns;
- automatic one-file Windows installer synchronization, clean-VM tests, checksums, and signed GitHub build provenance.

Verified with 33 Python tests, dark/light startup, 30 live theme switches across 9 dialogs, Verilator lint, self-checking LED/PWM and 30-byte UART simulations, and Tang Primer 20K place/route at 27 MHz (345.90 MHz reported maximum).
